Hugo is a [static site generator][] written in [Go][], optimized for speed and designed for flexibility. With its advanced templating system and fast asset pipelines, Hugo builds your project in seconds, often less.

Hugo's flexible framework, multilingual support, and taxonomy system make it a good fit for these types of sites:

- Corporate, government, nonprofit, education, news, event, and project sites
- Documentation sites
- Image portfolios
- Landing pages
- Business, professional, and personal blogs
- Resumes and CVs

Use Hugo's embedded web server during development to see changes to content, structure, behavior, and presentation as you make them. Then deploy your site to your host, or push changes to your Git provider for automated builds and deployment.

Use [modules][], including themes, to share content, assets, data, translations, templates, and configuration with other projects through public or private Git repositories.

Learn more about Hugo's [features][], [privacy protections][], and [security model][].
