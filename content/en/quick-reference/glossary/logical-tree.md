title: logical tree

A _logical tree_ is the hierarchy of [_nodes_](g) in a Hugo project, organized by their [_logical paths_](g). Just as file paths form a file tree, logical paths form a logical tree. Unlike the file tree, the logical tree omits file extensions and language, role, and version identifiers, represents each [_leaf bundle_](g) as a single node, and includes pages not backed by a file, such as `taxonomy` and `term` pages.
