---
title: publication path
params:
  reference: /content-management/organization/#url-paths
---

A _publication path_ is the location of a published file, relative to the `public` directory. For a page, Hugo derives the publication path from its URL path, the [_output format_](g), and the project configuration. For example, Hugo publishes the page with URL path `/posts/post-1/` to `posts/post-1/index.html`. With a multihost project, the publication path also begins with the language key.
