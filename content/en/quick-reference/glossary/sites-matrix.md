A _sites matrix_ is a map that selects [_sites_](g) by [_language_](g), [_version_](g), and [_role_](g), where the value of each key is a [_dimension matcher_](g). In front matter, a cascade, or a content mount, it selects the sites to publish the content to, creating a separate page for each site. In a `layouts` mount, it selects the sites that use the templates. In a segment or page matcher, it selects the sites to match.

  See also: [_sites complements_](g).
