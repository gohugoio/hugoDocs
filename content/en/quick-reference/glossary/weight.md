---
title: weight
---

A _weight_ is a numeric value used to position an element within a sorted [_collection_](g). Assign weights using non-zero integers. Lighter items float to the top, while heavier items sink to the bottom. Hugo places unweighted or zero-weighted elements at the end of the collection. You can assign weights to pages, menu entries, languages, [_roles_](g), versions, and output formats.
