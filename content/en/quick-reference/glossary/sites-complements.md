A _sites complements_ is a map that selects [_sites_](g) by [_language_](g), [_version_](g), and [_role_](g), where the value of each key is a [_dimension matcher_](g). Defined in front matter, a cascade, or a content mount, it adds the content to the page collections of the selected sites without creating new pages. Each page keeps the URL of its own site.

  See also: [_sites matrix_](g).
