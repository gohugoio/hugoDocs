## Prerequisites

Hugo does not require Git, Go, or Dart Sass for every project, but many projects use one or more of them.

Install [Git][] if you plan to do any of these tasks:

- Build Hugo from source
- Use [Hugo modules][]
- Install a theme as a Git submodule
- Access [commit information][] from a local Git repository
- Deploy your site to a [CI/CD](g) platform using one of the [hosting guides][]

Install [Go][] if you plan to do either of these tasks:

- Build Hugo from source
- Use Hugo modules

Install [Dart Sass][] to transpile Sass to CSS.
