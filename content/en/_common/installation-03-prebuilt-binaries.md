## Prebuilt binaries

Prebuilt binaries are available for many operating systems and architectures. Visit the [latest release][] page, and scroll down to the Assets section.

Follow these steps to install a prebuilt binary:

1. Download the archive for the desired edition, operating system, and architecture.
1. Extract the archive.
1. Move the executable to the desired directory.
1. Add this directory to the `PATH` environment variable.
1. Verify that you have _execute_ permission on the file.

Consult your operating system documentation if you need help setting file permissions or modifying your `PATH` environment variable.

If you do not see a prebuilt binary for the desired edition, operating system, and architecture, install Hugo using another method.

[latest release]: https://github.com/gohugoio/hugo/releases/latest
