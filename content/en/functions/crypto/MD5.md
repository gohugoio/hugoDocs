## Usage

The `crypto.MD5` function returns the MD5 checksum of the given input, encoded to a hexadecimal string.

## Examples

```go-html-template
{{ crypto.MD5 "Hello world" }} → 3e25960a79dbc69b674cd4ec67a72c62
```
